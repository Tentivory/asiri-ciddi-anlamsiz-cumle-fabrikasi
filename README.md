# Aşırı Ciddi Anlamsız Cümle Fabrikası

Bu repository, insanlık tarihinin en önemli projelerinden biridir. Amacı, tamamen anlamsız ama aşırı ciddi cümleler üreterek evrenin anlamsızlığını kanıtlamaktır.

## Nasıl Çalışır?

1. Python scriptini çalıştırın.
2. Üretilen cümleleri okuyun.
3. Hiçbir şey anlamadığınızı fark edin.
4. Bu durumu felsefi bir zafer olarak kabul edin.

## Uyarı

Bu yazılım hayatınızı değiştirmez. Aksine, daha da anlamsız hale getirebilir. Kullanımı tamamen kendi sorumluluğunuzdadır.

## Kurulum

```bash
python anlamsiz_cumle_fabrikasi.py
```
